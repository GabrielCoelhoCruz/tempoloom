# Glossary

One name per concept. Specs, code and UI use these names.

| Term | Meaning |
|---|---|
| Planner | The week view where the user sees and changes the schedule. |
| Managed event | A calendar event that Tempoloom created and keeps up to date. |
| External event | Any other calendar event, such as a meeting. |
| Hours set | Named weekly time windows. Built in: work hours, personal hours, meeting hours. Users can add custom sets. |
| Task | Work with a total duration and an optional due date. Tempoloom splits it into chunks and places them. |
| Chunk | One managed event that holds part of a task's duration. |
| Habit | A recurring routine with an ideal time and ideal days, such as lunch or a workout. |
| Focus time | A weekly goal of uninterrupted work time, placed as managed events. |
| Flexible meeting | A recurring meeting with other people that Tempoloom moves to the best common time. |
| Booking link | A public page where other people book time with the user. |
| Recovery buffer | Free time placed after meetings. |
| Travel buffer | Time placed before and after an event that has a location. |
| Break buffer | Time placed between task and habit events. |
| No-meeting day | A day on which meetings are blocked or discouraged. |
| Calendar mirroring | Copying events from one calendar to another as blocks, so both calendars show the same busy time. |
| Priority | P1 (critical), P2 (high), P3 (medium), P4 (low). Higher priority wins a conflict. |
| Lock | A user decision that a managed event must not move. |
| Defense | How a managed event shows on the calendar: free (others can book over it) or busy. |
| Next up | The task the user should work on now. |
| Event tag | A text marker in an event title that changes how Tempoloom treats the event, for example `#tl_free`. |
| Color rule | A rule that sets an event's calendar color from its category. |
| Stats | Reports of how the user's time was spent. |
| Team | A group of users who share settings, booking links and analytics. |
| Automation | A saved rule that creates or changes managed events when a condition is met. |
| Assistant chat | A text interface to plan and change the schedule in natural language. |
| Reference product | The commercial planner whose functions Tempoloom matches. See `docs/clean-room.md`. |
